# Engagement System

## Objective

Create a game that players naturally want to return to because progress is satisfying, goals are visible and systems keep unfolding.

## Retention model

```
Immediate feedback
      +
Visible next goal
      +
Meaningful upgrade
      +
New discovery
      +
Long-term progression
      =
Strong retention
```

## Session architecture

### First 30 seconds
- understand click;
- receive first reward;
- see passive production;
- see next goal.

### First 5 minutes
- unlock automation;
- complete a mission;
- hit a milestone;
- activate a gameplay boost;
- discover the next system.

### First session
- unlock a second production line;
- discover zones;
- understand daily rewards;
- distinguish Coins from money;
- optionally discover Earn.

## "One more" triggers

Healthy reasons to continue:
- upgrade is close;
- milestone is near;
- mission is almost done;
- new building is one purchase away;
- active gameplay boost;
- event objective progress.

Avoid:
- fear of losing money;
- fake scarcity;
- deceptive timers;
- forced autoplay;
- confusing withdrawal flows;
- monetized gambling mechanics.

## Reward cadence

Suggested starting targets:
- instant: click feedback;
- 30-90 sec: micro upgrade;
- 3-10 min: mission/milestone;
- session: unlock;
- daily: streak;
- weekly: event/league;
- long-term: prestige/season.

These are tuning targets, not promises.

## Mastery

The player should eventually make decisions about:
- production;
- upgrade ordering;
- boosts;
- prestige timing;
- missions;
- event strategy.

The goal is to turn an initially simple clicker into a lightweight optimization game.

## Ethical monetization

Preferred:
- rewarded gameplay ads;
- optional cosmetics;
- optional convenience;
- eligible sponsored tasks;
- eligible reward partners.

The money system stays separate from gameplay randomness and wagering.
