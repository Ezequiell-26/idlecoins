# Product Vision

## Goal

Build a serious rewards platform where the idle game is the primary engagement loop and the earning layer is transparent, sustainable and auditable.

## Core loop

1. The player enters the game.
2. Clicking and idle production generate game Coins.
3. Coins buy upgrades, automation, boosts and progression.
4. Missions create short-term goals.
5. Rewarded experiences can accelerate progression with non-cash game rewards.
6. Valid external tasks/offers may create pending monetary rewards.
7. Validated rewards move from pending to available balance.
8. The user can request a payout once eligibility and minimum thresholds are met.

## Product separation

### Game Coins

Used for progression:
- upgrades
- buildings
- boosts
- prestige
- events
- cosmetics

Game Coins are not assumed to be withdrawable.

### Earn Balance

Represents validated monetary value generated through eligible revenue events.

The Earn Balance has:
- pending balance
- available balance
- withdrawn balance
- immutable transaction history

## Product principles

- No fake earnings.
- No client-authoritative wallet.
- No direct ad-to-cash conversion through prohibited rewarded-ad mechanics.
- No payout before the corresponding revenue event is validated.
- Every external integration is replaceable.
- Every money movement is auditable.
