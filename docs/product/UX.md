# UX Architecture

## Primary navigation

Game | Earn | Missions | Wallet | Referrals | Profile

## Game screen

The game should immediately communicate:
- current Coins
- Coins per second
- click action
- available upgrades
- active boosts
- next meaningful unlock

## Earn screen

The user must be able to distinguish:
- game-only rewards
- pending monetary rewards
- available monetary balance

Never label pending rewards as withdrawable.

## Wallet

Show:
- available balance
- pending balance
- payout history
- minimum withdrawal
- status of each withdrawal

## Trust UX

When a reward is pending, explain the state instead of showing an ambiguous number.

When an account is restricted, show an actionable but non-sensitive reason category.
